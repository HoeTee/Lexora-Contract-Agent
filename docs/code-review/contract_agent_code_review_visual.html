判断方法

只比较当前调用路径上的有效限制。上游数值大于下游阀门时，多出的调用者只会等待。

时间配置执行顺序

时间配置 当前值 只控制什么 到期结果
pending / queued timeout 60s / 7200s 未被领取的任务 watchdog 收敛状态
wait_timeout_seconds 600s 等待 Redis 槽 未发 HTTP 就失败
lease_seconds 600s Redis 槽计数有效期 不会自动取消 HTTP
Agent HTTP timeout 30s 一次 Agent 请求 当前 attempt 超时
DocxIndex HTTP timeout 120s 一次检索模型请求 当前 attempt 超时
Celery task hard limit 未配置 整份合同运行时间 当前没有统一总时限
1000s 请求与 600s lease

600s 不会把请求截断。租约到期后，1000s 请求可能继续运行，但它已经不占 Redis 计数。新请求可取得该名额，真实并发可能突破 5。

安全关系：lease > 同一 Redis key 下最长的 HTTP timeout + 清理余量。
